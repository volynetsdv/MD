## Підсумковий аналіз ефективності системи (System Performance & Resource Summary)

1. **Фактична швидкодія та балансування обчислень на GPU:** Порівняльний аналіз фіксує пропускну здатність системи: **6.46 FPS** у Standard Mode ($B = 1.0$) проти **7.63 FPS** у Turbo Mode ($B = 4.0$, дельта: **+18.1%**). Середній час стадії інференсу на GPU $T_{\text{infer}}$ становить **66.8 мс** ($B = 1$) проти **43.7 мс** у пакетному режимі (-34.6%).
2. **Збереження точності та еквівалентність детекцій:** Метрики точності повністю збережені ($\text{mAP@50} = 0.6252 \to 0.6252$, $\text{Recall} = 0.7968 \to 0.7968$). Динамічне об'єднання фрагментів у пакети тензорів $[B, 3, S_m, S_m]$ забезпечує нульову втрату просторової деталізації та повну еквівалентність векторів детекцій відносно режиму $B = 1$.
3. **Безпека відеопам'яті (OOM-Safety) та стабільність пулів:** Динамічний розрахунок розміру пакета на основі поточної вільної VRAM (буфер $\alpha_{\text{safety}} = 0.80$) гарантує роботу без перевищення ліміту пам'яті (0 збоїв OOM). Телеметричний аудит підтверджує стабільність робочих пулів ($\Delta\text{RAM} = +0.24\text{ MB} < 50\text{ MB}$, $\Delta\text{VRAM} = +656.06\text{ MB}$).
4. **Інваріант Zero PCIe Readback:** Завдяки дисковій реплікації `shutil.copy2` та генерації супутніх JSON-кешів координат з GPU до Host RAM передаються виключно легковагові вектори детекцій ($O(N)$ цілей), що забезпечує понад 99.99% скорочення зворотного трафіку шини PCIe порівняно з пересиланням повного кадру.
