Середній час стадії інференсу на GPU $T_{\text{infer}}$ становить **68.2 мс** ($B = 1$) проти **44.5 мс** у пакетному режимі (-34.8%).
2. **Збереження точності та еквівалентність детекцій:** Метрики точності повністю збережені ($\text{mAP@50} = 0.6368 \to 0.6368$, $\text{Recall} = 0.8012 \to 0.8012$). 3. **Безпека відеопам'яті (OOM-Safety) та стабільність пулів:** Динамічний розрахунок розміру пакета на основі поточної вільної VRAM (буфер $\alpha_{\text{safety}} = 0.80$) гарантує роботу без перевищення ліміту пам'яті (0 збоїв OOM). Телеметричний аудит підтверджує стабільність робочих пулів ($\Delta\text{RAM} = +5.57\text{ MB} < 50\text{ MB}$, $\Delta\text{VRAM} = +679.81\text{ MB}$).
4. **Інваріант Zero PCIe Readback:** Завдяки дисковій реплікації `shutil.copy2` та генерації супутніх JSON-кешів координат з GPU до Host RAM передаються виключно легковагові вектори детекцій ($O(N)$ цілей), що забезпечує понад 99.99% скорочення зворотного трафіку шини PCIe порівняно з пересиланням повного кадру.
